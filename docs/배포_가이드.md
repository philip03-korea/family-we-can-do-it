# 배포 가이드 (무료 호스팅)

FamTalk 프론트엔드는 정적 빌드(`dist/`)라 **무료 호스팅**에 올릴 수 있습니다.
설치형(PWA)이라 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 비용 ₩0.

> 어느 쪽을 골라도 됩니다. **Cloudflare Pages**(트래픽 무료·빠름) 또는 **Vercel**(가장 간단) 추천.

---

## 공통 빌드 설정
- **Framework preset**: Vite
- **Root directory**: `frontend`
- **Build command**: `npm run build`
- **Output directory**: `dist`
- **환경변수 2개** (둘 다 공개돼도 안전한 anon 값):
  - `VITE_SUPABASE_URL`
  - `VITE_SUPABASE_ANON_KEY`

SPA 라우팅(새로고침 404 방지)은 이미 설정돼 있습니다:
- Cloudflare: `frontend/public/_redirects`
- Vercel: `frontend/vercel.json`

---

## A) Cloudflare Pages
1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. `philip03-korea/family-we-can-do-it` 저장소 선택
3. 빌드 설정 입력:
   - Root directory: `frontend`
   - Build command: `npm run build`
   - Build output directory: `dist`
4. **Environment variables** 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 추가
5. **Save and Deploy** → 몇 분 뒤 `https://famtalk.pages.dev` 같은 주소 생성

## B) Vercel
1. https://vercel.com → **Add New** → **Project** → 저장소 Import
2. **Root Directory** 를 `frontend` 로 지정 (Edit 클릭)
3. Framework: Vite 자동 인식 / Build: `npm run build` / Output: `dist`
4. **Environment Variables** 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 추가
5. **Deploy** → `https://famtalk.vercel.app` 같은 주소 생성

## 📱 모바일 접속 (가족 폰에서 사용)
- **localhost(`npm run dev`)는 폰에서 안 열림** → 위처럼 배포해서 생긴 **공개 HTTPS 주소**로 접속.
- 마이크/음성/PWA 설치는 **HTTPS에서만** 작동 → 배포 주소면 자동 OK.
- **홈 화면에 추가(PWA 설치)**
  - iPhone(Safari): 공유 버튼 → "홈 화면에 추가"
  - Android(Chrome): ⋮ 메뉴 → "앱 설치" / "홈 화면에 추가"
- **음성 기능 호환성**
  | 기능 | Android Chrome | iPhone(Safari/Chrome) |
  |------|----------------|------------------------|
  | 듣기(TTS) | ✅ | ✅ |
  | 따라 말하기 / Speaking 음성인식(STT) | ✅ | ❌ (iOS 미지원) |
  - iPhone에서는 음성인식 대신 **타이핑**으로 사용. 앱이 자동 감지해 안내 문구를 보여줌.
  - iPhone 발음 평가가 꼭 필요해지면 추후 **클라우드 STT(Whisper)** 를 선택 기능으로 추가 가능.
- Supabase → Authentication → **URL Configuration** 에 배포 주소를 Site URL/Redirect 로 등록해야 로그인 정상.
