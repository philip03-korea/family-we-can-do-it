# 푸시 알림 + 아침 알람 설정 (무료)

앱 코드·DB·함수는 이미 배포돼 있어요. **시크릿 4개만 설정**하면 알림이 작동합니다.
(웹푸시는 무료. iOS는 16.4+ 이고 "홈 화면에 추가"로 설치한 PWA에서만 알림이 와요. 안드로이드는 잘 됩니다.)

## 1) Edge Function 시크릿 설정
이미 생성된 VAPID 키입니다(공개키는 앱에 들어가 있음). 아래를 그대로 등록하세요:

```bash
supabase secrets set VAPID_PUBLIC=BJRx5cvNi-uKdJrgWLAD3V0ZGkxZwb537WyqC4qzEZBIvchxDwLqNqHG1OwfgQGynUvwhYDXd3fHfSriDpJkktM
supabase secrets set VAPID_PRIVATE=sGmBjHOanNcHpDiRZKmEPZ1cq86ymkjJqrMY9d6FWWI
supabase secrets set VAPID_SUBJECT=mailto:philip970329@gmail.com
supabase secrets set CRON_SECRET=famtalk-cron-7am-7Yq2
```
> `send-push` 함수는 이미 배포됨(`supabase functions deploy send-push --no-verify-jwt`). 시크릿만 넣으면 됩니다.

## 2) 앱에서 알림 켜기 (각자)
- 대시보드 맨 아래 **⚙️ 설정 → 🔔 푸시 알림 토글 ON** → 권한 "허용"
- **테스트 알림 보내기** 로 확인
- iPhone: Safari로 접속 → 공유 → "홈 화면에 추가" → 그 앱에서 켜야 작동

## 3) 매일 아침 7시 알람 (선택)
시크릿 설정 후, Supabase SQL Editor 에서 `database/step10_push.sql` 하단의
cron 블록 주석을 풀고 `<CRON_SECRET>` 을 `famtalk-cron-7am-7Yq2` 로 바꿔 실행하세요.
(07:00 KST = 22:00 UTC)

## 동작 방식
- 🔔 켜면 그 기기가 구독되어 `push_subscriptions` 에 저장
- 테스트/아침 알람은 `send-push` 함수가 web-push(VAPID)로 발송
- 매일 아침 cron → 전체 가족에게 "오늘의 단어·집안일" 알림
