## 1. 하음이 면접 노트 — 무엇이 들어 있나

요청 순서대로 누적:

1. 공통 기초 — PREP 답변 공식, 30초 자기소개 템플릿, 지원동기, 좋아하는 작가 답변법
2. 예상질문 은행 — 6유형(정체성·포폴·취향·진로·인성·돌발) + 답변 포인트
3. 학교별 심층 — 청강대 / 백석예대 / 한국영상대 (2026학년도 요강 수치 반영, 2027 재확인 표기)
4. 실기·즉석 드로잉 — 상황표현·칸만화·웹툰, 청강 20분 시간배분, **청강 즉석드로잉 예시 주제 25+**, **백석 실기(상황표현) 예시 주제**
5. **즉석 드로잉 자가 채점표** — 7항목 100점 자동 합산·등급·약점 팁 + 연습 기록장
6. 포트폴리오 가이드 + **페이지별 코멘트 프레임** (평가자가 보는 것/강해지는 법/감점)
7. **모의 면접 대본** 1회차(학교별 1~4) + **2회차 심화·압박(5~8)**
8. D-7→당일 체크리스트(localStorage 저장), 마인드셋

### 확인된 요강 수치 (2026학년도, 검색으로 확인 — 학교 사이트 직접 열람은 클라우드 네트워크에서 차단됨)

- **청강대** 만화콘텐츠스쿨 315명(웹툰만화 190 · 만화캐릭터일러 25 신설 · 웹소설 100). 면접전형 = 면접 100%(+포폴), 실기전형 = 실기 60 + 학생부 40(자율·융합 실기 100). 정시 면접전형 약 10명. 3테이블 부스 면접, 즉석 드로잉 20분.
- **백석예술대(서울 방배, bau.ac.kr)** 영상학부 만화애니메이션전공 — **실기전형·면접전형 둘 다 운영**(택1). 면접전형 = 학생부 40 + 면접 60, 포폴 지참 시 가산점. 수시1차 만화애니+게임 실기 63·면접 27 / 정시 실기 25·면접 10. 실기 유형: 상황표현·기초디자인·스토리보드·이야기구성 계열(원서 때 선택).
  - ⚠️ 처음엔 "실기 없음"으로 적었다가 정정함. 백석대학교(천안)·백석문화대(천안, 실제 '웹툰과')와 혼동 주의.
- **한국영상대** 만화웹툰콘텐츠과 — 실기전형 학생부 40 + 실기 60, 화지 배부·화판 불가, 상황표현·칸만화·웹툰 택1.

### ⚠️ 사무실 PC 세션(2026-09-19, 앱 면접 탭)과 수치가 다른 곳 — 교차 확인 필요

- 한국영상대: 사무실 세션은 "만화웹툰전공 **면접 60 + 교과 40**, 실기 택1 4시간, 10분 구술 4항목", 이번 노트는 "**실기 60 + 학생부 40**". 전공·전형(면접전형 vs 실기전형)이 달라서일 가능성이 크다. 2027 요강에서 하음이 지원할 전형으로 확정 후 한쪽을 고칠 것.
- 앱(`frontend/src/data/webtoon.js` 의 `SCHOOL_INTERVIEWS`)과 이 노트 중 무엇을 정본으로 둘지 결정 필요.

6. 영어 단어장 70+ (주제별, "뜻 가리기" 토글)
7. 시험 대비 질문 10 + 모범답안, 에세이 연결어
