# 입시박사 설정 가이드

「대학 가이드」(하울)와 「웹툰 입시」(하음) 화면 오른쪽 아래에 떠 있는 🎓 **입시박사** 버튼의 서버 설정이다.

## 구조 — 왜 이렇게 만들었나

```
앱(브라우저)  →  Supabase Edge Function 'tutor'  →  LLM(OpenAI 또는 Gemini)
                        ↑ API 키는 여기에만 있다
```

**API 키는 절대 브라우저에 넣지 않는다.** 넣으면 누구나 개발자도구로 꺼내 도용할 수 있고,
그대로 과금으로 이어진다. 기존 AI 회화(`chat` 함수)와 똑같은 원칙이다.

박사는 **앱 화면에 실제로 실린 가이드 내용만 근거로** 답한다
(`career.js` · `webtoon.js` 의 `tutorContext()` 가 그 내용을 문자열로 만들어 넘긴다).
없는 대학·전형을 지어내지 않고, 해마다 바뀌는 숫자는 단정하지 않고 "요강 확인"으로 넘기도록
시스템 프롬프트에 박아 뒀다.

---

## 1) 제공자 고르기

`tutor` 함수는 **시크릿이 있는 쪽을 자동으로 고른다.**

| 조건 | 쓰는 것 |
|---|---|
| `OPENAI_API_KEY` 가 있으면 | OpenAI (`OPENAI_MODEL`) |
| 없으면 | Gemini (`GEMINI_API_KEY`) — AI 회화가 이미 쓰는 무료 키 |

**지금 당장은 아무것도 안 해도 Gemini 로 동작한다.** 아래 2)만 하면 된다.
OpenAI 로 바꾸고 싶으면 3)까지 하면 된다.

---

## 2) 함수 배포 (필수 — 이걸 해야 버튼이 동작한다)

```bash
npm install -g supabase          # 이미 있으면 생략
supabase login
cd <저장소>
supabase link --project-ref ghmroezwdwkvruygrqzv
supabase functions deploy tutor
```

배포 전에는 버튼을 눌러도
「입시박사가 아직 연결되지 않았어요」라는 안내만 뜬다.

---

## 3) OpenAI 로 붙이기 (선택)

### 먼저 알아둘 것 — 이메일만으로는 연결되지 않는다

계정 이메일(예: `philip970329@gmail.com`)은 **어느 서비스에도 인증 수단이 아니다.**
OpenAI 를 쓰려면 그 계정으로 로그인해 **API 키를 직접 발급**해야 한다.
비밀번호를 어디에도 적어 두지 말 것.

1. https://platform.openai.com/api-keys 접속 → 그 계정으로 로그인
2. **Create new secret key** → 키 복사 (`sk-...`)
   - ChatGPT 구독(Plus/Pro)과 **API 사용료는 별개**다. API 는 결제수단 등록이 필요하다.
3. 시크릿 등록

```bash
supabase secrets set OPENAI_API_KEY=sk-...
supabase secrets set OPENAI_MODEL=<모델명>
supabase functions deploy tutor
```

### ⚠️ 모델명은 본인 계정에서 확인할 것

`OPENAI_MODEL` 기본값은 `gpt-5.1` 로 넣어 두었지만, **이 이름이 그 계정에서 실제로 쓸 수 있는지는
확인이 필요하다.** OpenAI 모델 이름은 자주 바뀌고 계정마다 접근 권한이 다르다.

사용 가능한 모델 목록은 이렇게 확인한다:

```bash
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY" | grep '"id"'
```

모델명이 틀리면 박사가 「잠시 대답을 못 하고 있어요」를 띄우고,
Supabase 대시보드 → Edge Functions → tutor → Logs 에 실제 오류가 찍힌다.

---

## 4) 사용량 관리

- `chat` 함수와 **같은 일일 카운터**(`bump_ai_usage`)를 쓴다. 한 사람이 하루에 쓸 수 있는
  AI 호출 상한이 `AI_DAILY_LIMIT`(기본 100) 로 걸려 있어 폭주하지 않는다.
- 상한을 바꾸려면 `supabase secrets set AI_DAILY_LIMIT=200`

---

## 5) 문제가 생기면

| 화면에 뜨는 말 | 원인 |
|---|---|
| 아직 연결되지 않았어요 | `tutor` 함수 미배포, 또는 키가 하나도 없음 |
| 오늘 질문 한도를 모두 썼어요 | `AI_DAILY_LIMIT` 초과 — 내일 초기화 |
| 오늘 AI 사용량이 다 찼어요 | 제공자 쪽 쿼터/크레딧 소진 (429) |
| 잠시 대답을 못 하고 있어요 | 모델명 오타·권한 없음 등 — Edge Function 로그 확인 |

로그: Supabase 대시보드 → Edge Functions → `tutor` → Logs
