# 입시박사 설정 가이드

「대학 가이드」(하울)와 「웹툰 입시」(하음) 화면 오른쪽 아래에 떠 있는 🎓 **입시박사** 버튼의 서버 설정이다.

---

## 먼저 — 「구독료로 쓸 수 있나?」

**결론: 앱에 붙이는 건 구독으로 안 된다. 대신 무료 등급으로 사실상 0원에 쓰고 있다.**

이걸 헷갈리면 돈이 새거나, 안 되는 걸 붙들고 시간을 쓴다.

| | 무엇 | 앱에서 쓸 수 있나 |
|---|---|---|
| **구독** (ChatGPT Plus/Pro, Gemini Advanced 등) | 사람이 웹·앱에서 직접 대화하는 것 | ❌ **안 된다** |
| **API** (API 키) | 프로그램이 서버에서 호출하는 것 | ✅ 이것만 가능 |

두 요금은 **완전히 별개**다. ChatGPT Plus 를 결제해도 API 사용료는 따로 청구되고,
Gemini Advanced 를 결제해도 Gemini API 는 따로다. 구독료 안에 API 가 포함되지 않는다.

**그래서 이 앱은 Gemini API 의 무료 등급을 쓴다.** 결제수단 등록 없이 무료 한도 안에서
동작하고, 5인 가족이 쓰는 정도로는 한도에 닿기 어렵다.
(한도는 바뀔 수 있다 — https://aistudio.google.com/app/apikey 에서 확인)

여기에 두 겹을 더 걸어 뒀다.

- **캐시**: 같은 화면에서 같은 질문은 저장된 답을 꺼내 쓴다. 호출 자체가 없다.
- **일일 한도**: `AI_DAILY_LIMIT`(기본 100) — 한 사람이 하루에 쓸 수 있는 상한.

---

## 구조

```
앱(브라우저)  →  Supabase Edge Function 'tutor'  →  Gemini(무료 등급)
                        ↑ API 키는 여기에만 있다
```

**API 키는 절대 브라우저에 넣지 않는다.** 넣으면 누구나 개발자도구로 꺼내 도용할 수 있고,
그대로 과금으로 이어진다. 기존 AI 회화(`chat` 함수)와 같은 원칙이다.

박사는 **앱 화면에 실제로 실린 가이드 내용만 근거로** 답한다
(`career.js` · `webtoon.js` 의 `tutorContext()` 가 그 내용을 문자열로 만들어 넘긴다).
없는 대학·전형을 지어내지 않고, 해마다 바뀌는 숫자는 단정하지 않고 "요강 확인"으로 넘긴다.

## 유료로 바꾸고 싶어지면 (지금은 할 필요 없다)

`TUTOR_PROVIDER` 를 바꾸지 않는 한 **유료 제공자로 자동 전환되지 않는다.**
다른 용도로 `OPENAI_API_KEY` 를 넣어 두더라도 입시박사에서는 돈이 나가지 않는다.

```bash
supabase secrets set TUTOR_PROVIDER=openai
supabase secrets set OPENAI_API_KEY=sk-...          # platform.openai.com/api-keys 에서 발급
supabase secrets set OPENAI_MODEL=<계정에서 확인한 모델명>
supabase functions deploy tutor
```

### 모델명은 반드시 계정에서 확인할 것

모델 이름은 자주 바뀌고 계정마다 접근 권한이 다르다. **이름을 추측해서 넣으면 조용히 실패한다.**

```bash
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY" | grep '"id"'
```

여기 나오는 목록에 있는 이름만 쓴다.
(참고: OpenAI 의 **Codex** 는 코딩용 에이전트 제품이고, 대화 모델(GPT)과는 별개다.
「코덱스 5.x」 같은 이름은 이 API 에서 쓰는 모델명이 아니다.)

돌아오려면 `supabase secrets set TUTOR_PROVIDER=gemini` 후 재배포하면 된다.

## 문제가 생기면

| 화면에 뜨는 말 | 원인 |
|---|---|
| 아직 연결되지 않았어요 | `tutor` 함수 미배포, 또는 고른 제공자의 키가 없음 |
| 오늘 질문 한도를 모두 썼어요 | `AI_DAILY_LIMIT` 초과 — 내일 초기화 |
| 오늘 AI 사용량이 다 찼어요 | 제공자 쪽 무료 한도/크레딧 소진 (429) |
| 잠시 대답을 못 하고 있어요 | 모델명 오타·권한 없음 등 — 로그 확인 |

로그: Supabase 대시보드 → Edge Functions → `tutor` → Logs
