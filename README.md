## FamTalk — 우리 가족 영어 프로젝트

> 같은 사다리, 각자의 출발점. 다섯 식구가 하나의 레벨(A→F)을 오르며 매일 영어로 성장하고, 매주 공통 주제로 모여 함께 말한다.

| 하울 | 고1 | E (심화) | TOEFL 별도 트랙 병행 |
| 하람 | 중1 | B (기초) | 기초 단어·재미·습관 |

### 🎯 핵심 원칙

- **단어·말하기 중심** — 쓰기는 최소 (TOEFL 필수만)
- **발음·억양 체크** — STT + 피치 분석으로 교정
- **레벨 사다리 A→F** — 한 줄기 콘텐츠, 각자 시작점 선택
- **주간 공통 토론** — 같은 주제, 레벨별 준비, 함께 대화
- **하울 TOEFL 트랙** — 사다리와 별도로 시험 준비·모의 체험
